# Peekaboo

**一个让人呼吸顺畅的微信增强模块。**

> [!NOTE]
> 本模块由个人同名的 iOS 插件移植而来，以自用为主，随个人需求维护；部分移植功能尚未在安卓端全部测完，使用前请知悉。

## 使用要求

- **框架**：需支持现代 **libxposed API 102**（不支持旧版 Xposed 82 及仅 API 100/101 的框架）
- **系统**：Android 8.1 及以上
- **微信**：严格限定官方微信 **8.0.80（3220）arm64**，版本不匹配不会生效；不支持改包名、多开与企业会话

## 启用方式

1. 安装模块 APK（无桌面图标属正常现象）。
2. 在框架管理器中启用模块，勾选作用域 **微信（`com.tencent.mm`）**。
3. 彻底结束并冷启动微信，进入 **我 → 设置 → Peekaboo** 按需开启功能（默认全部关闭）。

## 主要功能

- **密友管理**：按账号隐藏指定好友与群聊（不删聊天记录），支持搜索框口令/指纹面容解锁、退后台或摇动自动隐藏，以及通知、来电与免打扰联动。
- **消息增强**：消息防撤回、长消息防折叠、消息时间显示、屏蔽输入状态、删除会话保留记录，以及复读、左右滑快捷引用/转发与语音转发。
- **登录模式**：提供平板模式，切换并重启重新登录后可与另一台手机同时登录（未登录时也可在登录页右上角菜单切换）。

## 问题反馈

遇到异常或功能未生效时，请发邮件至 [push@muse.ai](mailto:push@muse.ai)，并尽量附上诊断日志方便定位：

1. 在微信进入 **我 → 设置 → Peekaboo → 诊断日志**，打开 **记录日志**。
2. 复现问题（若排查加载或入口不显示，开启后先重启微信再复现）。
3. 回到该页面点击 **复制日志** 或 **分享日志** 并附在邮件中（日志仅包含版本号与纯数字状态码，不含账号、联系人或聊天内容）。

来信请一并说明手机型号、系统版本、LSPosed 框架版本及复现步骤。
